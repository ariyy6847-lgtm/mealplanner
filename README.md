## About

Plans a week of meals from a recipe list and generates a shopping list.

## Features

- Dependency-free Node server
- Responsive, hand-written frontend
- Live API endpoints for stats and health
- Easy to restyle and extend

## Install

```bash
git clone https://github.com/ariyy6847-lgtm/mealplanner.git
cd mealplanner
```

## Usage

```bash
npm start

open http://localhost:8080
```
